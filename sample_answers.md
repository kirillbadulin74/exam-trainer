### Вопрос 1. Переменные и базовые типы данных в Python

**Тезисно**
1. Переменная — это имя, связанное со значением; отдельно объявлять тип не нужно (динамическая типизация).
2. Базовые типы: `int` (целое), `float` (дробное), `str` (строка), `bool` (истина/ложь).
3. Присваивание — знак `=`: слева имя, справа значение.
4. Узнать тип — `type(x)`; преобразовать — `int()`, `float()`, `str()`.

**Примеры**
```python
x = 5            # int
pi = 3.14        # float
name = "Аня"     # str
is_ok = True     # bool
print(type(x))   # <class 'int'>
```

**Текстом**
Переменная в Python — это просто имя, которое ссылается на какое-то значение. В отличие от многих языков, тип заранее указывать не нужно: Python сам определяет его по значению, это называется динамической типизацией. Основных типов четыре: целые числа, дробные числа, строки и логический тип с двумя значениями — истина и ложь. Присваивание делается знаком равно: слева имя, справа значение. Если нужно узнать тип значения, есть функция type, а чтобы превратить одно в другое — функции с именами типов: целое, дробное, строка.

### Вопрос 2. Списки: создание, индексация, основные методы

**Тезисно**
1. Список — упорядоченная изменяемая коллекция значений в квадратных скобках.
2. Индексация с нуля; отрицательный индекс отсчитывает с конца.
3. Срез `list[a:b]` возвращает подсписок от a до b (не включая b).
4. Частые методы: `append` (добавить в конец), `pop` (удалить и вернуть), `len` (длина).

**Примеры**
```python
nums = [10, 20, 30]
print(nums[0], nums[-1])  # 10 30
print(nums[0:2])          # [10, 20]
nums.append(40)           # [10, 20, 30, 40]
```

**Текстом**
Список — это упорядоченный набор значений, записанный в квадратных скобках через запятую. Он изменяемый: элементы можно добавлять, удалять и заменять. Доступ к элементам идёт по индексу, причём нумерация начинается с нуля, а отрицательный индекс отсчитывает с конца — минус первый это последний элемент. Можно взять срез, указав диапазон через двоеточие: он вернёт подсписок, при этом правая граница не включается. Из частых методов: добавить в конец, удалить и вернуть элемент, а также функция длины, которая говорит, сколько элементов в списке.

### Вопрос 3. Условный оператор if / elif / else

**Тезисно**
1. Условный оператор выбирает, какой код выполнить, в зависимости от истинности условия.
2. Синтаксис: `if условие:` — двоеточие и отступ обязательны; ветки `elif` и `else` необязательны.
3. Условие — логическое выражение (сравнения `==`, `<`, `>`, операторы `and`, `or`, `not`).
4. Тернарная форма для короткого выбора: `a if условие else b`.

**Примеры**
```python
n = 7
if n > 0:
    print("положительное")
elif n == 0:
    print("ноль")
else:
    print("отрицательное")

sign = "чёт" if n % 2 == 0 else "нечёт"
```

**Текстом**
Условный оператор нужен, чтобы программа принимала решения: выполнять тот или иной блок кода в зависимости от условия. Пишется он словом if, дальше условие и двоеточие, а сам блок обозначается отступом — это обязательно. Если основное условие не выполнилось, можно проверить другое через elif, а ветка else срабатывает, когда ни одно условие не подошло. Условие — это логическое выражение: сравнения на равенство, больше, меньше, которые можно объединять словами «и», «или», «не». Для короткого выбора между двумя значениями есть тернарная форма: значение, затем условие, затем альтернатива — всё в одну строку.
