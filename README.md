# Exam Trainer — голосовой тренажёр устных ответов с ИИ-проверкой

CLI-тренажёр для подготовки к устному экзамену: показывает билет, слушает твой
**устный** ответ, расшифровывает речь **локально** и оценивает ответ с помощью LLM —
как доброжелательный, но требовательный экзаменатор.

## Что делает

1. Показывает вытянутый билет (по номеру, по формулировке через нечёткий поиск или случайный).
2. Ты отвечаешь **вслух** и сохраняешь запись с диктофона (любой формат аудио).
3. `faster-whisper` расшифровывает речь в текст — **локально, офлайн** (с GPU, если есть CUDA).
4. LLM сверяет ответ с эталоном и выдаёт разбор: **оценка N/10**, что раскрыто,
   что упущено (по пунктам), фактические ошибки и совет.

Ответ можно вводить и текстом (`--text`) — тогда шаг распознавания пропускается.

## Стек и что демонстрирует проект

- **Python** — CLI на `argparse`, парсинг Markdown регулярными выражениями, `pathlib`.
- **Распознавание речи** — `faster-whisper` с автоматическим выбором GPU (CUDA) → CPU
  и потоковым выводом прогресса по сегментам.
- **Нечёткий поиск** — сопоставление билета по формулировке (пересечение слов + `difflib.SequenceMatcher`).
- **Работа с LLM** — OpenAI-совместимый клиент, потоковый (streaming) вывод,
  проектирование системного промпта под роль экзаменатора.
- **Конфигурация** — секреты и параметры через `.env` (`python-dotenv`), без хардкода.

## Установка

```bash
pip install -r requirements.txt
```

Зависимости: `openai`, `python-dotenv`, `faster-whisper`.
При первом запуске `faster-whisper` сам скачает нужную модель Whisper.

## Настройка

Скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env        # Linux / macOS
copy .env.example .env      # Windows (cmd / PowerShell)
```

```dotenv
OPENAI_API_KEY=твой_ключ          # обязательно
OPENAI_BASE_URL=https://…/v1      # если используешь прокси/шлюз (иначе оставь пустым)
OPENAI_MODEL=gpt-4o-mini          # модель-экзаменатор (по умолчанию gpt-4o-mini)
HF_TOKEN=                         # необязательно: только повышает лимиты загрузки Whisper
EXAM_AUDIO=/путь/к/записи.m4a     # путь к аудио по умолчанию (необязательно)
```

Обязателен только `OPENAI_API_KEY` — остальные строки можно оставить пустыми.
Модели Whisper публичные и скачиваются **без** токена HuggingFace; `HF_TOKEN` нужен
лишь чтобы поднять лимиты запросов и ускорить первую загрузку.

## Запуск

```bash
python exam_trainer.py                 # спросит билет (Enter — случайный), ответ голосом
python exam_trainer.py 2               # сразу билет №2
python exam_trainer.py --random        # случайный билет без вопросов
python exam_trainer.py --text          # ответ текстом, без аудио
python exam_trainer.py --model base    # точнее распознавание (медленнее)
python exam_trainer.py --audio ans.m4a # взять готовый аудиофайл
```

Флаги дублируются по-русски: `--текст`, `--модель`, `--случайный`.

### Ввод ответа текстом

В режиме `--text` ответ можно писать или вставлять в несколько строк и абзацев.
Завершить ввод — любым из трёх способов: **два раза Enter** на пустой строке,
строка с одной **точкой**, либо `Ctrl+Z` + Enter (в Windows) / `Ctrl+D` (в *nix).
Программа печатает, сколько символов приняла, — так сразу видно, что текст дошёл.

### Модели Whisper

| Модель   | Скорость | Качество | Когда                                  |
|----------|----------|----------|----------------------------------------|
| `tiny`   | ⚡⚡⚡    | среднее  | по умолчанию — хватает для разбора      |
| `base`   | ⚡⚡      | хорошее  | если термины распознаются неточно       |
| `small`  | ⚡        | высокое  | нужна точность и есть GPU                |
| `medium` | медленно | лучшее   | сложные записи / много терминов          |

Разбор оценивает содержание, а не дословность, поэтому `tiny` обычно достаточно:
на реальном прогоне полного ответа он дал оценку 9/10. Если видишь, что термины
превращаются в кашу и экзаменатор считает названный тезис пропущенным — бери `base`.

Скорость сильно зависит от процессора: быстрые int8-вычисления CTranslate2 требуют
AVX2, и на старых CPU без него распознавание идёт в разы медленнее (на Pentium N3540
`tiny` — примерно ×0,7 от реального времени, `base` — ×0,25).

С NVIDIA GPU (CUDA) распознавание идёт на видеокарте автоматически, иначе — на CPU.

## Свои билеты

Репозиторий содержит демо-набор `sample_answers.md`, чтобы тренажёр работал сразу.
Чтобы тренироваться на своих билетах, положи рядом файл `Экзамен_ответы_v2.md`
в том же формате — тренажёр возьмёт его автоматически (приоритетнее демо-набора).

Формат одного билета:

```markdown
### Вопрос N. Формулировка вопроса

**Тезисно**
1. ...

**Примеры**
```python
...
```

**Текстом**
Связный устный ответ...
```

Тренажёр использует весь текст билета как эталон для проверки, а первую строку — как формулировку вопроса.
